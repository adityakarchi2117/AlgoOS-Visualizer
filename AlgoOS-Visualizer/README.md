# AlgoOS Visualizer

A simple visualization tool for **Data Structures & Algorithms** and **Operating System** concepts.

## Features

- **DSA**: Stack, Queue, Linked Lists, Trees, Heaps, Graphs, Huffman Coding
- **OS**: CPU Scheduling (FCFS, SJF, Round Robin), Memory Management (FIFO, LRU, Optimal), Disk Scheduling, Banker's Algorithm

## Tech Stack

- **Backend**: C++ (Algorithm implementation)
- **Frontend**: Python Streamlit (Web interface)

## Quick Start

1. **Install Python dependencies**:
   ```bash
   pip install streamlit plotly pandas
   ```

2. **Compile C++ files**:
   ```bash
   ./build.bat
   ```

3. **Run the app**:
   ```bash
   cd frontend
   streamlit run app.py
   ```
